#  CyberBot – Cybersecurity Awareness Chatbot

##  Overview

CyberBot is a C# console-based chatbot designed to educate users about **cybersecurity best practices**.
It interacts with users in real-time, answering questions about online safety topics such as phishing, passwords, and safe browsing.

---

##  Features

*  Interactive chatbot conversation
*  ASCII art logo display
*  Voice greeting (WAV file support)
*  Cybersecurity awareness responses
*  Randomized answers for better interaction
*  Input validation (name & questions)
*  Keyword-based response system

---

## Topics Covered

* Password Security
* Phishing Attacks
* Safe Browsing
* Malware Protection
* Two-Factor Authentication (2FA)
* VPN Awareness

---

##  Technologies Used

* C# (.NET)
* Console Application
* System.Media (for sound)
* System.Drawing (for ASCII image rendering)

---

##  How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/cyberbot.git
cd cyberbot
```

### 2. Build the project

```bash
dotnet build
```

### 3. Run the application

```bash
dotnet run
```
